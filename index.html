NISAR Level-3 ATBD Cookbook

This Cookbook compiles the NISAR Level-3 Algorithm Theoretrical Basis Document notebooks into a single location.

The ATBD notebooks are synced with the originals in their upstream repositories each night.

ATBDs¶

The notebooks execute algorithms that demonstrate adherence to NISAR Level-2 Science Requirements.

The Level-3 products generated by the ATBD notebooks address:

  1. Wetland inundation

  2. Crop area detection

  3. Aboveground biomass estimation

  4. Sea ice motion tracking

  5. Solid earth displacements (Secular, coseismic, and transient)

  6. Forest disturbance detection

Running the Notebooks¶

Running in a Jupyter Hub¶

If you are working in a Jupyter Hub that allows you to build Pixi environments, such as OpenSARLab, use the following steps to run the notebooks in this cookbook.

  1. Clone the repository:

     git clone https://github.com/ASFOpenSARlab/NISAR_ATBD_Cookbook.git

  2. Run the notebooks/software_environment.ipynb notebook.

Running on Your Own Machine¶

If you are interested in running this material locally on your computer, you will need to follow this workflow:

(Replace “your_account/your_cookbook” with the GitHub org or user name and title of your cookbook repository)

  1. Clone this repository:

     git clone https://github.com/ASFOpenSARlab/NISAR_ATBD_Cookbook.git

  2. Move into the NISAR_ATBD_Cookbook directory

    cd NISAR_ATBD_Cookbook

  3. Launch in Jupyter Lab with the included Pixi environment

    pixi run lab
